# v0.1.0 Release notes

2026-11-13 · 翻译集合（`otools-fanyi`）

## 特性

- 9 个网页翻译站入口、Tabs 切换、iframe 懒加载与切站保留状态。
- 站点启停与恢复默认，本机保存配置；统一输入、复制文本与浏览器打开兜底。
- **百度、搜狗、必应**启用已证实预填；无已证实模板的站点保留原 URL，复制文本后粘贴。
- **DeepL / Google**使用浏览器入口和可复制链接，不内嵌、不承诺自动预填。

## 本次核验范围与待验证

2026-11-13 在 **ZCode 内置浏览器**实测，页面快照显示 **6 站** iframe 翻译界面（百度、腾讯、有道、搜狗、必应、彩云），其中 **3 站**确认测试源文与译文（百度、搜狗、必应）。界面渲染不代表其余站点翻译已通过。

CNKI 两次快照仍为空 iframe，未完成加载；保留入口与浏览器兜底。DeepL 顶层页可加载、Google 顶层页可达，但均未确认自动预填。macOS OTools WKWebView、native `openExternal` 与市场安装 **未实测，手动待验证**。不宣称 9 站全部可用；完整证据见 [PREFILL.md](PREFILL.md)。

## 隐私

插件不收集遥测，不保存翻译输入或历史。统一输入仅在用户点击“翻译”等明确提交操作时传给所选目标服务；主动打开已支持站点的预填浏览器链接也可能携带输入。无模板站不附加文本，由用户复制后手动粘贴。第三方网页的网络请求、cookie 与文本处理遵循其各自政策。

构建、测试、打包/校验命令与手动验收清单见 [README](../README.md)。
